## Up to 807× faster than h3-js

for `compactCells` on a `k=20` disk containing 1,261 cells. iPhone XS, iOS 18.7.9, React Native
0.87.0, Hermes, 20-run median, 2026-08-31. Every result was verified against `h3-js` 4.5.0 for
equivalence.

[![react-native-nitro-h3 against h3-js, median milliseconds per workload](/react-native-nitro-h3/img/benchmark.svg)](/react-native-nitro-h3/benchmark/)

## Install

```bash
bun add react-native-nitro-h3 react-native-nitro-modules
```

```bash
npm install react-native-nitro-h3 react-native-nitro-modules
```

## One call

```ts
import { gridDisk, latLngToCell } from 'react-native-nitro-h3'

const cell = latLngToCell(37.7749, -122.4194, 9) // 0x89283082803ffffn
const ring = gridDisk(cell, 1) // BigUint64Array of 7 cells
```
